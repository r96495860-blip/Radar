# Radar

Клиентский мод для Fabric 1.21.9: нажмите **G**, введите ник игрока и нажмите
**Применить**. Выбранный игрок будет обведён красным контуром на вашем клиенте,
даже если сервер не включает для него эффект свечения. Игрок должен быть
загружен в текущем мире. Чтобы отключить подсветку, очистите ник и нажмите
**Применить**. Мод не требуется устанавливать на сервер.

## Сборка

Используйте Java 21 или новее и выполните:

```sh
./gradlew build
```

Готовый мод будет создан в `build/libs/`.
