# Radar

Клиентский мод для Fabric 1.21.9 с хэллоуинским меню: нажмите **G**, отметьте
игроков в списке или найдите ник через поиск и нажмите **Добавить**. Выберите
цвет из палитры для всех отмеченных игроков или нажмите цветной квадратик рядом
с конкретным ником, чтобы переключить только его цвет. Нажмите **Применить**,
чтобы сохранить выбор. Обводка рисуется только на вашем клиенте; игрок должен
быть загружен в текущем мире. Мод не требуется устанавливать на сервер.

## Сборка

Используйте Java 21 или новее и выполните:

```sh
./gradlew build
```

Готовый мод будет создан в `build/libs/`.
