# Radar

Клиентский мод для Fabric 1.21.9: нажмите **G**, введите ник игрока и нажмите
**Применить**. Выбранный игрок будет подсвечиваться эффектом свечения, пока
он находится в загруженном мире. Чтобы отключить подсветку, откройте меню,
удалите ник и нажмите **Применить**.

## Сборка

Используйте Java 21 или новее и выполните:

```sh
./gradlew build
```

Готовый мод будет создан в `build/libs/`.
