# Radar

Клиентский мод для Fabric 1.21.9: нажмите **G**, отметьте игроков в списке или
найдите ник через поиск и нажмите **Добавить**. Нажмите **Применить**, чтобы
сохранить выбор. Выбранные игроки обводятся красным контуром на вашем клиенте,
даже если сервер не включает для них эффект свечения. Для обводки игрок должен
быть загружен в текущем мире. Мод не требуется устанавливать на сервер.

## Сборка

Используйте Java 21 или новее и выполните:

```sh
./gradlew build
```

Готовый мод будет создан в `build/libs/`.
